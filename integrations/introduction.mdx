PERSCOM provides multiple options for integrating your personnel data with external services:

- **API**: Access and manage your data programmatically
- **Automations**: Trigger actions automatically based on events
- **OAuth 2.0**: Enable secure authentication between applications
- **SDKs**: Build integrations faster with official libraries
- **Webhooks**: Receive real-time notifications when data changes
- **Widgets**: Embed personnel data displays on your website

Select an integration from the sidebar to learn more.
