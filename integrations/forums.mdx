PERSCOM partners with [Forumify](https://forumify.net) to provide a white-label forum integration. Forumify offers next-generation forum software with robust features to enhance community interaction and collaboration.

## Features

The Forumify PERSCOM plugin provides:

- Single sign-on (SSO) with your PERSCOM account
- Automatic rank and position synchronization
- Member roster integration
- Permission-based forum access
- And many more features...

## Get Started

Visit [Forumify](https://forumify.net) to learn more about their forum software, then install the official PERSCOM plugin.
